Como configurar
1
Power Automate → Novo fluxo → gatilho "Quando uma solicitação HTTP é recebida"
2

{"Data":"","Linhas":"","VV":"","Codigo":"","Quantidade":1,"Responsavel":"","Obs":""}
3

5
Salve → copie a URL HTTP POST
